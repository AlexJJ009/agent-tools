# Learning Artifact Compiler

Turn verified guided-learning state into durable writing without inventing new evidence or hiding uncertainty.

## Workflow

1. Confirm the DAG, evidence anchors, and retrieval checks already exist or request them from the orchestrator.
2. Choose artifact form: tutorial, blog, study note, review memo, or audit report.
3. Preserve source boundaries and provisional labels.
4. Include reconstruction and transfer checks unless the user explicitly asks for prose only.

Read `references/artifact-compilation.md` for artifact patterns. Use the shared contract at `../teaching-reconstruction/references/artifact-contract.md` for durable manifests.

Use `../teaching-reconstruction/assets/learning-artifact-template.md` as the default scaffold.

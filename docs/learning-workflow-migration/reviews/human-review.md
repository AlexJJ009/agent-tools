## 1. 学习：能讲清楚，也给你留下输出空间

[完整示范](../pilot/learning-example.md)开头先展示两个来源各生成四个候选、统一评分与并列选择，再解释参数含义。它响应的是“先完整示范，不要考我”，因此没有安排练习。

[练习与反馈片段](../pilot/practice-exchange.md)展示另一种明确要求练习的场景：保留学习者的句子，指出其证据缺口，再让学习者改写。这里的学习者句子由评测者编写，只用于检验 Agent 的反馈方式。

重点看三件事：背景是否足够；示范与解释是否过长或过短；练习时给出的填空框架是否帮助你继续写，还是已经替你完成了过多判断。建议保留“直接示范”和“先尝试再反馈”两种方式，由当前请求决定。若材料需要修改，反馈可只定位到一个段落，并说明缺什么背景或希望少给哪一步答案。

## 2. 写稿：直接交付可修改的文本

[英文稿件](../pilot/manuscript-draft.md)的 Introduction 是直接起草结果，Alternative Proposal 是尚未执行的研究建议。它没有要求你先通过练习。

重点看这份稿件是否能作为继续修改的起点：论证是否连贯；已有证据与待验证设想是否分得清；是否还需要更充分的背景或更短的表达。建议按“对实际写作是否有用”评价，不要求你认可示例选题，更不把认可稿件记成你已经练会写作。

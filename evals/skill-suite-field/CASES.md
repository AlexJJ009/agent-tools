# 工作区维护与自然触发评估

本组预先定义六个自包含项目现场，覆盖用户提到的实际失误形态：该清的没有清、恢复证据或最终材料误删、交接状态过期、学习过程中没有给可答题目，以及交付时不必要地进入教学。它们是合成现场，不冒称真实用户历史或长期学习测量。

每题比较同一模型的目标 skill 可用与不可用，两组其他技能、资源、用户级指令和工具相同。四个模型沿用此前固定顺序：gpt-6.1-sol、gpt-6-sol、gpt-5.6-sol、gpt-6-luna；各组两次，共 96 个位置。评分器和预算由运行协议冻结，本文件不授权改动模型或 skill。

| 题目 | 自然请求与现场 | 目标 / 共同技能 | 主要结果 |
| --- | --- | --- | --- |
| F01 | 完成发票导入后收拾工作区；动态依赖与试验材料混放 | cleaner / 无；explicit | 真正移除已替代试验，保留活跃数据、最后 final、唯一观测、未决 draft 与用户注释 |
| F02 | 退役整组旧过程材料并整理现有交接；旧文件循环互引，恢复状态有冲突 | cleaner / 无；explicit | 已授权的旧集合实际退役，现有记录与 receipt 对齐，未决远端确认和恢复材料保留 |
| F03 | 正在学代码、正常路径已理解，继续理解元素共享，尚有两分钟 | teaching-reconstruction / retrieval-practice；discoverable | 先解释当前边界，然后在当前回复给一题具体可答的短检验，留作答机会 |
| F04 | 相同源码切回接口交付，明确不继续学习、不出题 | teaching-reconstruction / retrieval-practice；discoverable | 直接正确说明接口边界和提醒，不续练习或改文件；空答不能通过 |
| F05 | 完成 preview 实现并交付，已有废弃探针和同步需求 | cleaner / 无；discoverable | 功能正确，共用格式策略、清掉废弃实现、更新现有说明，保留旧接口和范围 |
| F06 | 按已采纳决定维护项目，次日需要接手 | cleaner / 无；discoverable | 补齐既有 ADR 的真实理由和限制，纠正危险恢复指导，不改决定、不删未决数据 |

F01/F02 是显式暴露目标 skill 后的能力测量；F03–F06 的用户提示不点名 skill，runner 只提供可发现元数据，不要求读取或调用目标正文。正文读取是独立诊断，不能拿“没有看到工具读取”替代产物失败，也不能据此断言不存在原生注入。自然触发观察只能描述本组教学正负例和 cleaner 正向收尾，不是全体技能的触发准确率。F03 两组都拥有 retrieval-practice，测的是增加教学编排 skill 的差异；对照组也能直接选练习，不能假定它应当失败。

判断以结果为主：允许等价迁移、合并说明、不同正确例子和不同实现布局，不限定工具顺序或固定命令。原始输入数据和唯一原始观测采用字节保护；文档是否保留重要信息、链接是否仍有效，由语义评分结合实际文件判断。F05 不要求特定 helper 或 AST 结构，主要核对公开行为和是否保留两份可分叉策略。编排题不把强制工具阅读当主项，依据实际解释和练习即可。

F06 的维护义务来自已有证据：task.md 记载已经采纳的真实理由，docs/README.md 指向已有 ADR，而 usage 仍声称遗留 pending 总可以删除。补齐当前 Accepted 决定不构成新架构决策，不要求新 ADR；不能凭空提出“凡交付必写 ADR”。F05 的初始仓库是干净的合成快照，没有声称真实未提交 diff；用户要求补齐 stub，运行中会产生实际开发改动。

所有题都使用已有便携项目记录，不提供真实 task-runtime 数据库。F02 的 receipt 是题目提供的合成事实，测如何维护文档和保留恢复材料，不测事务恢复、远端确认、数据库操作或任务关闭。也不测真正多轮交互、长期记忆、学习收益或提醒系统。

## 运行前校准

每题 `grader_side.calibration` 都有人工编写的 `good`、`bad`、`empty`：`final_answer` 是候选回复；`file_overrides` 覆盖初始文件，`null` 表示删除。先在相同 rubric 下检查 good 主项通过、bad/empty 主项失败，再启动正式试次。参考样例、oracle、checks 和 machine_checks 都只在评分侧，绝不注入被测环境。

`grader_side.machine_checks` 是评分副本中的离线 Python 检查，包含 `id`、`scope`、`code`。它们只承担可机械核验的部分：行为、字节保留、明确废弃项已删除、既有文档确实修改。语义 judge 判断完整主项、文档含义、练习质量和边界；不能把文件动过就判作维护正确。F03/F04 的机判护栏通过不等于主项通过，尤其无内容输出必须失败。F05 bad 样例特意实现正确功能但保留重复策略、废弃探针和过时说明，检验评分能否发现维护缺口，而不只是发现功能缺失。

正式结果至少分开报告：完成率、主项、约束、写作、目标正文读取观察。超时单列，不补成质量 false；重复 attempt 不扩大实验位置分母。有效完成配对和正文确认子集可能有选择偏差，均不能替代所有分配任务的结果。两次重复仅支持局部现象，不能据此改成某模型专用 skill，也不按六题总分给模型排名。

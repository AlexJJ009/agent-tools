# Practice Design Notes

Match the response format to the skill being practiced. Recognition, reconstruction, and free production provide different evidence; none is the universal format.

## Response formats

| Learning objective | Useful response format | Evidence limit |
|---|---|---|
| Notice which claim fits the evidence | Contrastive examples: choose among a few plausible formulations; optionally give one reason | Tests discriminative judgment, not independent drafting |
| Practice one missing qualifier or warrant | Cloze completion with a focused blank | The surrounding structure is supplied |
| Identify an unsupported inference | Mark the problematic phrase and explain or repair it | Tests diagnosis or local revision, not an entire argument |
| Organize an argument | Order sentences or assign their rhetorical moves | The ideas and wording are already supplied |
| Express a bounded claim | Write or revise a short paragraph from source facts | Record any supplied outline, wording, or model answer |
| Apply the idea in another setting | A near- or far-transfer task using a changed example | One successful example does not establish broad mastery |

For a user who explicitly wants a low-effort round, comparing three short versions can be enough. Make alternatives differ on the intended issue, such as causal overclaiming or the scope of a conclusion, rather than on an obviously silly distractor. Do not announce the answer before the attempt unless the user asks for a worked example. When drafting is the objective, leave space for the user's wording instead of replacing every attempt with selection questions. Vary formats across objectives; do not impose quotas or every format in one session.

## Check types

- Reconstruction: rebuild the mechanism or proof path from memory.
- Near transfer: apply the same idea with surface changes.
- Far transfer: choose whether the idea applies in a different setting.
- Audit: find a weak claim, missing prerequisite, or over-generalization.

## Scoring

Assess the requested objective: a choice can show discrimination; a rewrite can show local expression; an independent paragraph can show more of the argument construction. Check mechanism, boundary, and evidence use when relevant. Do not require exact wording or convert an assisted answer into a mastery claim.

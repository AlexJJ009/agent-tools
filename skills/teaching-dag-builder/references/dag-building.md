# DAG Building Notes

Prefer small, testable KCs over broad topics. A useful KC names a mental move the learner can perform.

## Edge audit

- Use `strict` when removing the prerequisite makes the target incoherent.
- Use `common` when most explanations assume it but an alternate path exists.
- Use `convenience` for fluency, analogy, or compression.

## Frontier audit

A frontier KC must have prerequisites satisfied, waived, or explicitly taught next. Reject frontier nodes whose missing prerequisite would force memorization.
